# ZERO 秘訣9の編集可能な図版ソース

このフォルダーは説明図の組版用です。ふとん便は説明用の架空サービスで、実際の販売・申し込みサイトではありません。フォーム・送信・決済機能はありません。全HTMLを noindex,nofollow としています。

- `figure-01.html`：メインコピーだけを比較するA/Bテスト
- `figure-02.html`：便利さ・清潔さ・家族での利用という3訴求
- `figure-03.html`：離脱の確認、長文の3ステップ化、修正後の確認
- `figure-04.html`：CVRとCPAの確認
- `figures.css`：PC幅950px／スマートフォン幅342pxの独立した組版
- `font-audit.js`：正規Webフォントの読み込み結果を `data-font-audit` に記録
- `assets/`：新規制作の架空サービス写真。元画像は制作ワークスペースに保持

見出し・数字は新ゴBold、説明・注記は新ゴRegularを使用。既存の購入済みMorisawa WebフォントのURLをそのまま使用し、フォントバイナリーの保存・再配布・ライセンス設定変更は行っていません。

図01の2案はメインコピー以外の写真・本文・料金・CTA・配置を共通の関数で生成しています。料金・配送条件も架空デザイン上の例です。図01の1,000人／30件・50件／3%・5%は計算用の仮例で、実績や必要サンプル数ではありません。図03の到達表示は実測ではありません。

編集後はテストドメイン上で `data-font-audit` が両書体の読み込みを確認してから、PC・スマートフォンそれぞれを書き出してください。本文ページでは軽量JPEGをpicture要素で切り替えます。

2倍解像度の画像書き出しでは `?export=2` を付けます。文字の再圧縮を避けるため、配信画像はブラウザーが書き出したJPEGをそのまま使用しています。CSS・検証JSのURLにはバージョンを付け、編集時には更新します。
