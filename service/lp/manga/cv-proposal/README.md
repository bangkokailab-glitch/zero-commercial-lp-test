## 事例の根拠状態

既存本体のstory-cvrには、Salon de Sixの「成約率約1.5倍」「ホームページで販売していた時との比較」が掲載されている。本提案ではその既存記載のみを扱う。元の計測データは未確認。CV定義・期間・訪問数・成約数・流入や商品条件の比較・掲載可否の確認が必要。

画面は既存`salon-hp-desktop.webp`と`salon-lp-fv-offer-jp.webp`を参照したカンプ。提案ページ下部に実画像も表示する。これらが計測期間中の画面と同一だったと主張しない。期間、件数、顧客コメント、売上などは捏造・追加していない。

確認が取れるまでは本体への追加を保留する。採用する場合は、数値を外した制作事例として先に紹介し、集計条件を確認できた後に数字と条件を併記する方法を提案。
