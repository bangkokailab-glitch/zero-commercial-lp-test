# 広告章・まとめの追加素材

2026-10-15 ユーザー承認：「計画との差分が残る3点」を反映する。

## 漫画

- `search-to-lp.webp`：広告4コマ目。検索広告からサービス専用LPへの流れ。
- `maps-to-website.webp`：広告7コマ目。マップの店舗情報からウェブサイトへの流れ。
- `mari-customer-focus.webp`：まとめ4コマ目。マリがスマホを脇に置き、目の前のお客様へメニューを説明する。

3枚とも1448×1086。組み込み画像生成で制作し、既存のマリ・斎藤さんとサロン背景を参照。縦横比を保ったままWebP形式に変換。生成画像の文字を後から描き直す加工は行っていない。

既存の広告2＋4コマに追加2コマを挟んで8コマ、既存のまとめ3コマの後に追加1コマを置いて4コマ。セリフは既存の順番表示制御に含める。境界線は共通の漫画枠を使用。

## 実スクリーンショット

撮影経緯・URL・寸法：`capture-provenance.json`。

- `google-search-live-20261015.jpg`：Google検索「バンコク 脱毛サロン」。Salon de Sixのスポンサー広告が表示された実画面。
- `google-maps-live-20261015.jpg`：Googleマップ「バンコク 焼肉」。Bully's Bangkokのスポンサー結果が表示された実画面。

ブラウザの実JPEGバイト列を保存。広告ラベルや店舗を合成・生成していない。広告はクリックしていない。アカウント表示などを撮影範囲から外し、マップの全体画面にはGoogle Mapsの表示と出典を残している。

スマホの拡大部分は同じマップ画像の左上407×298pxをCSSで表示している。別撮影・再描画ではない。全体画像も掲載し、画像タップで原寸を開ける。

検索広告で観測したリンク属性は `salon-de-six.com/jp/`。そのため、下の男磨きLPは「ご提案するリンク先の設計」として区別し、撮影した広告の現在の遷移先だとは断定しない。

Googleマップの掲載店舗は広告表示の実例であり、ZEROの運用実績ではない。ページにも明記している。広告形式や押す箇所によって、店舗情報、ウェブサイト、経路、電話などの遷移が異なる説明を保持。

参考：Google 広告ヘルプ「ローカル広告について」
https://support.google.com/google-ads/answer/3246303?hl=ja

## 確認

- 生成された検索・マップの旧説明画像は現行HTMLから参照しない。過去の素材として保存。
