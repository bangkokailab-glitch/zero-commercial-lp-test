## 実装

`../../flow-c.html` を `#production-flow` の共通B見出し直後に挿入。現行の `.back-content` 全体と置換する。共通B見出しは変更しない。`../../flow-c.css` を既存スタイルの後で読み込む。

最新修正では、原画Cのように漫画と見出し・本文を左右に並べる。本文を画像の下に分離していた実装は廃止。奇数は文章が左、偶数は文章が右。原画の人物と場面は同じ幅比率のままCSSで切り出し、各枠の中で縦中央に置く。人物を引き伸ばさず、本文の量に応じてカードが自然に伸びる。

見出しは19px以上、本文は16px以上（390px表示では約16px）。原画Cの短い説明を表面に戻し、元の詳しい説明は末尾の「各工程の詳しい内容を見る」に全文を保持している。番号タブ・紺金の独立枠・冒頭人物の比率は維持。クリップにはoverflow:clipを使い、アンカー移動で内部だけがスクロールする問題を避ける。

原画像内側の横範囲は x=16〜708（幅692）。各シーンの y/高さは 297/169、492/173、691/192、908/189、1123/187、1336/188、1550/194、1769/262。切り出しはCSSのみで画像ファイルを追加加工していない。

## 検品

生成原画と文字なし素材を目視比較し、人物・ポーズ・左右配置・8場面の順序を確認。最新修正は新たな画像生成を行わず、同じ素材を使用。元HTMLの全19段落が詳細開閉欄に同順で保持されていること、8カードと番号順、overflow:hiddenがないことを照合済み。360px/390px/PCのブラウザ確認は統合側で実施。

## 画像編集プロンプト要旨

採用Cの全場面・人物・表情・遠近・8枠・枠の高さ・背景・配色を維持し、全ての見出し/説明/番号/装飾文字を除去する。削除箇所は元のクリーム色にする。人物の大きさと位置を一切再構成しない。LINE・Googleロゴは文字なしの背景へ戻す。上部人物は保持、8枚のカードを統合・並べ替え・切り落とししない。
