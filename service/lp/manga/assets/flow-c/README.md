## 実装

## 検品

生成原画と文字なし素材を目視比較し、人物・ポーズ・左右配置・8場面の順序を確認。空の数字タブはWebフォント番号を載せる場所として保持。元HTMLから抽出した8つのh3と全段落がfragmentに同順で保持されていることを照合済み。360px/390px/PCのブラウザ確認は統合側で実施。

## 画像編集プロンプト要旨

採用Cの全場面・人物・表情・遠近・8枠・枠の高さ・背景・配色を維持し、全ての見出し/説明/番号/装飾文字を除去する。削除箇所は元のクリーム色にする。人物の大きさと位置を一切再構成しない。LINE・Googleロゴは文字なしの背景へ戻す。上部人物は保持、8枚のカードを統合・並べ替え・切り落とししない。
