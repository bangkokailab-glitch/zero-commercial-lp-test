## 修正時の完了条件

1. 既存の承認済み素材・コピー、ユーザーの未コミット変更を保護してローカルを修正する。
2. `node scripts/build-lp-assets.cjs` でバンドルを再生成し、差分・PC・スマホ（360px / 390px）の表示と関連操作を確認する。
3. 今回の依頼に属する変更だけをコミットし、テストサイトの `main` へ通常のpushで反映する。force push、無関係な変更の混入、秘密情報の追加は禁止。
4. GitHub Pagesの配信完了を待ち、キャッシュ更新付きの公開URLで文言・CSS・JS・画像と主要な動きを確認する。push成功だけで公開完了と報告しない。
5. 公開確認済みのテストURLと主な変更内容をユーザーに渡す。

ローカルだけで止めない。ただしユーザーが今回は提案のみ・ローカルのみ・公開停止と指定した場合はその指示を優先する。認証・競合・検証不合格などで反映できない場合は、未反映の範囲と理由を明示する。
