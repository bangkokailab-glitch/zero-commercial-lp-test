# C案｜流れが見える3カード

ZERO LPの `#strategy-expansion` を参照したZEROラボ用ファーストビューの比較案。中央の青いZEROシンボル、白帯、黄色と白の大見出し、細い白枠の3カードを採用し、学びから制作、公開後の改善へ進む流れを示す。

- 背景は参照LPそのものの `service/lp/images/mv.mp4` と `mv-img.jpg`。70%の暗色レイヤーを重ね、閲覧時のみ再生し、`prefers-reduced-motion` では静止画を表示する。
- 主コピー、補足コピー、創業文は指定どおりのHTMLテキスト。シンボルは既存SVG、ロゴの「ZEROラボ」はHTMLテキスト。
- 3枠の提案文は「知る／つくる／広げる」。枠を矢印と番号でつなぎ、参考LPの図解との親和性を作った。
- 新ゴ R/Bは許可済みテストホストで外部CSSを読み込む構成。フォントファイルを同梱していない。
- `preview-pc.jpg` は1392×900、`preview-sp.jpg` は390×844。`preview-check.json` はローカルの寸法・動作確認記録。公開先のフォント読み込みは統合・公開後に確認する。
- 本番サイトと既存ZERO LPは変更していない。

制作には `lp-production` と `imagegen` のスキルを確認した。当初、文字なし背景案をimagegenで生成したが、ユーザーから元LPの背景をそのまま使う指示があったため、生成画像は採用していない。
