# B案｜作字で見せる学びの流れ

参照は `service/lp/#strategy-expansion`。青い既存 ZERO シンボル、白帯、黄色と白の大きなコピー、3つの白枠を同じ順序で構成。B案は3つの動詞を一行のキービジュアルとして組み、白枠内は「見つける → 形にする → 広げる」という学びの流れにした。

背景はユーザー指定どおり、同じ ZERO LP の `service/lp/images/mv.mp4` と `mv-img.jpg` を直接参照する。モリサワ新ゴ R/B は既存の Web フォント CSS を参照し、本文・見出し・白帯・ロゴ文字を生きた HTML テキストにした。モーション低減設定時は動画を非表示にして既存ポスター画像を表示する。

コピーは既存指定の3文を変更せず、カード内だけを今回の提案文として作成。ユーザー選択前の比較用プレビューであり、本番サイトは変更していない。

`preview-pc.jpg` は1392×900、`preview-sp.jpg` は390×844、`preview-sp320.jpg` は320×700のローカル Chrome キャプチャ。3画面でコピー一致、ロゴと動画の読込・再生、横はみ出しなしを確認した。公開先での Web フォントの実読込は公開後の統合確認が必要。
