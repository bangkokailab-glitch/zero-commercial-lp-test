# A案｜ZERO LP の構成を引き継ぐ標準案

## 狙い

参照 LP の戦略セクションと同じ流れで、中央の青い ZERO シンボル、白い帯、黄と白の大きなコピー、矢印でつながる3つの白枠を配置した。3枠は制作会社の営業工程ではなく、ZEROラボの読者がたどる「知る → つくる → 育てる」を示す。

## 制作方法

- `lp-production` スキルの参考パターン確認と無形サービス向けの主コピー優先設計を適用。
- ユーザー指定により、背景画像と動画は既存 ZERO LP の `service/lp/images/mv-img.jpg` と `mv.mp4` をそのまま参照。生成画像への差し替えはしていない。
- 3つの指定コピー、ロゴ文字、枠内のテキストは HTML の生きた文字で、ZERO LP と同じモリサワ新ゴ R/B を参照する。
- 音を出さないループ動画を使い、画面外や `prefers-reduced-motion` では再生を止める。

## 確認

`capture.mjs` で PC 1392×900、スマホ 390×844、狭幅 320×720 を確認。横はみ出しなし。指定コピーは全文一致。動画再生、ロゴ表示、JavaScript エラーなし。ローカル表示ではWebフォントの許可ドメイン外となるため、モリサワ実読み込みは GitHub Pages 公開後に確認する。
