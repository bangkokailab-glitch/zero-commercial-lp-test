第1章基礎

LP（ランディングページ）

エルピー／ランディングページ

広告などから訪れた人へ、一つの商品やサービスの提案を伝え、資料請求・予約・購入などにつなげるページです。

具体例・使い方を見る

たとえば

店舗向けの清掃サービスを広告で案内し、その内容と料金、申し込み方法を一つのページで説明します。アクセス解析では「訪問者が最初に開いたページ」をLPと呼ぶこともあります。

第1章で詳しく学ぶ →

ホームページ

ホームページ

この用語集では、会社概要や事業、商品、採用など、複数の目的に応える企業の公式サイト全体を指します。

具体例・使い方を見る

たとえば

会社を知りたい人は会社概要へ、サービスを探す人はサービス一覧へ。読む人の目的に合わせて、必要なページを案内します。

第1章で詳しく学ぶ →

サービスページ

サービスページ

一つのサービスについて、対象となる人、提供内容、料金、利用の流れなどを詳しく説明するページです。

具体例・使い方を見る

たとえば

企業サイトの中に清掃サービスの紹介ページを作り、対応する施設や作業内容を説明します。LPと役割が重なる場合もあります。

第1章で詳しく学ぶ →

CV（コンバージョン）

シーブイ／コンバージョン

購入や問い合わせなど、サイトや広告で成果として決めた行動のことです。何を成果とするかは、目的に合わせて決めます。

具体例・使い方を見る

たとえば

資料請求を目的にしたLPなら、フォームの送信完了をCVとして数えます。ボタンを押しただけなのか、送信まで完了したのかを区別しましょう。

第1章で詳しく学ぶ →参考：Google 広告ヘルプ（コンバージョン） ↗

第2章目的・予算・発注

KPI（重要業績評価指標）

ケーピーアイ

目標に向かって進んでいるかを確かめるための指標です。売上などの最終目標につながる、途中の成果や行動を数字で追います。

具体例・使い方を見る

たとえば

LPから受注を増やしたい場合、問い合わせ数だけでなく、商談になった件数も確認します。数を増やすだけで目標に近づくのか、指標同士のつながりも考えます。

第2章で詳しく学ぶ →

CPA（コンバージョン単価）

シーピーエー

成果1件を得るために、いくらかかったかを表す指標です。広告では通常、広告費をコンバージョン数で割って計算します。

具体例・使い方を見る

たとえば

広告費が3万円、資料請求が10件なら、資料請求のCPAは3,000円です。資料請求は受注とは違うため、何を成果として計算した数字なのかをそろえて比べます。

第2章で詳しく学ぶ →参考：Google 広告ヘルプ（平均コンバージョン単価） ↗

LTV（顧客生涯価値）

エルティーブイ

一人のお客様との取引を通じて、どのくらいの価値が生まれるかを考える指標です。初回だけでなく、継続購入や追加の利用も含めて見ます。

具体例・使い方を見る

たとえば

定期サービスでは、月額料金だけでなく利用期間や提供コストも考えます。売上で計算するのか利益で計算するのか、どの期間を見るのかを決めてから比較します。

第2章で詳しく学ぶ →

ROAS（広告費用対効果）

ロアス

広告費に対して、どれだけの売上などの成果価値が生まれたかを表します。売上を成果価値とする場合は、売上÷広告費×100で計算します。

具体例・使い方を見る

たとえば

広告費が10万円、広告経由の売上が30万円ならROASは300％です。これは利益率ではありません。原価や人件費などを含めた採算は、別に確認する必要があります。

第2章で詳しく学ぶ →参考：Google 広告ヘルプ（広告費用対効果） ↗

第3章調査・戦略

ペルソナ

ペルソナ

届けたいお客様を具体的に考えるために、悩みや目的、購入時の不安などを整理した人物像です。調査した情報をもとに作ります。

具体例・使い方を見る

たとえば

「40代の経営者」だけでなく、「清掃の管理に時間がかかり、品質を落とさず外注したい」と状況まで整理します。想像で細かな設定を増やすこと自体が目的ではありません。

第3章で詳しく学ぶ →

3C分析

サンシーぶんせき

顧客・競合・自社の3つの視点で情報を整理し、事業や商品の方針を考える方法です。お客様が求めることと、自社が提供できることをつなぎます。

具体例・使い方を見る

たとえば

お客様の困りごと、他社の提案、自社の得意分野を書き出します。3つの表を埋めて終わりにせず、「誰の、どんな困りごとに応えるか」を決める材料にします。

第3章で詳しく学ぶ →

USP（独自の販売提案）

ユーエスピー

競合との違いのうち、お客様にとって選ぶ理由になる提案のことです。単に珍しいだけでなく、相手が求める価値と結び付いていることが大切です。

具体例・使い方を見る

たとえば

「早い」だけでなく、「急な予約変更でも当日対応できる」など、相手に何が役立つのかを考えます。その提案が実際に提供できるか、裏付けも確認します。

第3章で詳しく学ぶ →

カスタマージャーニー

カスタマージャーニー

お客様が商品を知り、検討し、購入・利用するまでの行動や気持ちの変化を整理したものです。各段階で必要な情報を考えるために使います。

具体例・使い方を見る

たとえば

サービスを検索したときは内容を知りたくても、申し込み直前には費用や解約条件が気になるかもしれません。段階ごとの疑問に合わせて、広告やLPの説明を整えます。

第3章で詳しく学ぶ →

第4章企画・構成

コンセプト

コンセプト

誰に、どのような価値を、どんな考え方で届けるかをまとめた提案の中心です。構成・文章・デザインが同じ方向を向くための軸になります。

具体例・使い方を見る

たとえば

清掃サービスなら「忙しい店長が、衛生管理を安心して任せられる」と提案の軸を決めます。その軸に合う説明や根拠を選び、関係の薄い情報を増やしすぎないようにします。

第4章で詳しく学ぶ →

オファー

オファー

お客様に行動してもらうために提示する、商品・サービスの内容や条件です。価格だけでなく、体験、資料、保証などの提案も含まれます。

具体例・使い方を見る

たとえば

「初回の相談を無料で受けられる」と案内するなら、相談できる内容や時間、その後に費用が発生する条件も説明します。魅力と条件の両方を伝えることが大切です。

第4章で詳しく学ぶ →

ワイヤーフレーム

ワイヤーフレーム

ページに載せる情報と、その順番や配置を示した設計図です。色や装飾を作り込む前に、必要な説明と読み進める流れを確認します。

具体例・使い方を見る

たとえば

見出し、サービスの説明、実績、料金、申し込み案内を四角い枠で並べます。写真が未完成でも、何をどこで伝えるかを関係者で確認できます。

第4章で詳しく学ぶ →

導線

どうせん

訪問者が必要な情報を読み、次の行動へ進めるように用意した経路です。LPの中だけでなく、広告からLP、フォーム、その後の案内までを考えます。

具体例・使い方を見る

たとえば

広告で無料相談を案内したら、LPでも相談内容を説明し、申し込みフォームへつなぎます。フォームの送信後に何が起きるかも案内すると、流れが分かりやすくなります。

第4章で詳しく学ぶ →

第5章コピー・文章

キャッチコピー

キャッチコピー

読み手の関心を引き、商品やサービスの価値を短く伝える言葉です。目立たせるだけでなく、「自分に関係がある」と分かることが大切です。

具体例・使い方を見る

たとえば

誰に向けた提案なのか、何の困りごとを解決するのかを考えて書きます。印象的な言葉でも、本文で説明できない効果や実績は約束しないようにします。

第5章で詳しく学ぶ →

ベネフィット

ベネフィット

商品やサービスを使うことで、お客様にとって何がよくなるのかを表した価値です。機能や特徴そのものではなく、利用する側の変化を伝えます。

具体例・使い方を見る

たとえば

「予約を自動で受け付ける」は機能の説明です。「電話対応の時間を減らし、接客に集中しやすくなる」とすると、使う人にとっての価値を説明できます。

第5章で詳しく学ぶ →

CTA（行動喚起）

シーティーエー

資料請求や予約など、読み手に次の行動を案内する要素です。ボタンだけでなく、その近くにある説明やテキストリンクも含まれます。

具体例・使い方を見る

たとえば

「送信」だけでなく「無料相談を申し込む」と書くと、押した後の行動が分かります。何を受け取れるのか、料金や所要時間なども必要に応じて添えます。

第5章で詳しく学ぶ →

FAQ（よくある質問）

エフエーキュー

お客様からよく寄せられる疑問と、その答えをまとめたものです。申し込み前の不安を解消したり、必要な条件を確認したりするために使います。

具体例・使い方を見る

たとえば

費用、対応エリア、導入までの期間など、実際に聞かれる質問に答えます。料金や重要な条件はFAQだけに隠さず、本文の該当箇所でも説明します。

第5章で詳しく学ぶ →

第6章デザイン

FV（ファーストビュー）

エフブイ／ファーストビュー

ページを開いたときに、スクロールする前に見える範囲です。何のページで、誰にどんな価値を提供するのかを伝える役割があります。

具体例・使い方を見る

たとえば

同じLPでもスマホとパソコンでは見える範囲が違います。画像だけでなく、見出しや説明がそれぞれの画面でどこまで見えるかを確かめます。

第6章で詳しく学ぶ →

レスポンシブデザイン

レスポンシブデザイン

画面の幅などに合わせて、文字や画像、並び方を調整する設計です。スマホでもパソコンでも、情報を読み、操作しやすい状態を目指します。

具体例・使い方を見る

たとえば

パソコンでは2列の情報を、スマホでは1列に並べます。全体を小さく縮めるのではなく、文字の読みやすさやボタンの押しやすさも確認します。

第6章で詳しく学ぶ →

UI（ユーザーインターフェース）

ユーアイ

人がサービスや機器を使うときに触れる、画面や操作部分です。Webページでは、メニュー、ボタン、入力欄などが当てはまります。

具体例・使い方を見る

たとえば

どのボタンを押すのか、入力で間違えた場所はどこかが分かるようにします。見た目の統一に加えて、操作した結果が伝わることも大切です。

第6章で詳しく学ぶ →

EFO（入力フォーム最適化）

イーエフオー

入力フォームでの迷いや負担を減らし、必要な情報を正しく送信しやすくする取り組みです。入力項目や説明、エラー表示などを見直します。

具体例・使い方を見る

たとえば

必須項目を明示し、電話番号の入力形式を案内します。項目を減らすだけでなく、受け取った後の対応に必要な情報がそろうかも確認します。

第6章で詳しく学ぶ →

第7章コーディング・計測・公開

コーディング

コーディング

設計やデザインをもとにコードを書き、ブラウザーで表示・操作できるページにする作業です。見た目の再現と、必要な動作の実装を行います。

具体例・使い方を見る

たとえば

見出しや本文をHTMLで組み、CSSで配置を整え、必要に応じてJavaScriptでメニューなどを動かします。フォームの受信には、サーバー側などの仕組みも必要です。

第7章で詳しく学ぶ →

WordPress

ワードプレス

Webサイトのページや記事を管理・公開するための、オープンソースのソフトウェアです。管理画面から文章や画像を更新できます。

具体例・使い方を見る

たとえば

企業サイトやメディアの記事を更新する仕組みとして使えます。テーマやプラグインで機能を追加できますが、選定や更新、セキュリティの管理も必要になります。

第7章で詳しく学ぶ →参考：WordPress 日本語公式サイト ↗

GA4（Google アナリティクス4）

ジーエーフォー

Webサイトやアプリで、利用者の行動を分析するためのGoogleのツールです。ページの表示やクリックなどをイベントとして記録・分析します。

具体例・使い方を見る

たとえば

どこから訪問し、どのページを読み、問い合わせに進んだかを調べます。必要な行動が計測されているか、設定と実際の記録を確認してから数字を読みます。

第7章で詳しく学ぶ →参考：Google アナリティクス公式ヘルプ ↗

計測タグ

けいそくタグ

ページの閲覧や申し込みなどを計測ツールへ伝えるために設置するコードです。何を、どのタイミングで記録するかを決めて設定します。

具体例・使い方を見る

たとえば

問い合わせ完了を数えるなら、送信成功時に記録されるようにします。同じ行動を二重に数えていないか、必要な同意やデータの扱いにも注意して確認します。

第7章で詳しく学ぶ →

第8章集客・広告

SEO（検索エンジン最適化）

エスイーオー

検索エンジンがページの内容を理解し、必要とする人が見つけやすくなるように整える取り組みです。内容の充実と、読み取りやすい構造の両方を考えます。

具体例・使い方を見る

たとえば

読者の疑問に答える内容を用意し、見出しやリンクで整理します。検索広告とは別の取り組みで、特定の対策をすれば必ず上位に出るというものではありません。

第8章で詳しく学ぶ →参考：Google 検索セントラル（SEO） ↗

検索広告

けんさくこうこく

検索した言葉などに応じて、検索結果に表示される広告です。検索している人の目的と、広告の説明、移動先のLPの内容をそろえて考えます。

具体例・使い方を見る

たとえば

店舗の清掃を探している人へ広告を出すなら、LPでも店舗向けの対応内容を説明します。広告で約束した内容が、移動先で見つかることが大切です。

第8章で詳しく学ぶ →

CPC（クリック単価）

シーピーシー

広告のクリック1回にかかる費用です。平均CPCは、クリックにかかった費用の合計をクリック数で割って計算します。

具体例・使い方を見る

たとえば

クリックにかかった費用が1万円、クリック数が100回なら、平均CPCは100円です。設定する入札単価の上限と、実際の平均クリック単価は別の数字です。

第8章で詳しく学ぶ →参考：Google 広告ヘルプ（平均クリック単価） ↗

CTR（クリック率）

シーティーアール

広告などが表示された回数に対して、クリックされた回数がどれくらいあるかを表します。クリック数÷表示回数×100で計算します。

具体例・使い方を見る

たとえば

広告が1,000回表示され、20回クリックされたならCTRは2％です。人数の割合とは限りません。また、クリック率が高くても、問い合わせや購入につながるかは別に確認します。

第8章で詳しく学ぶ →参考：Google 広告ヘルプ（クリック率） ↗

第9章分析・改善

CVR（コンバージョン率）

シーブイアール

訪問や広告の操作などに対して、成果として決めた行動がどのくらい発生したかを表す割合です。計測ツールによって、計算の分母が異なる場合があります。

具体例・使い方を見る

たとえば

LPへの訪問1,000回を分母とし、問い合わせ20件ならCVRは2％です。Google 広告では計測対象の広告操作が分母になります。比較するときは期間、成果、分母の定義をそろえます。

第9章で詳しく学ぶ →参考：Google 広告ヘルプ（コンバージョン率） ↗

LPO（LP最適化）

エルピーオー

LPを訪れた人が内容を理解し、必要な行動に進みやすくなるよう改善する取り組みです。データや利用者の声をもとに、課題と変更内容を決めます。

具体例・使い方を見る

たとえば

料金が分かりにくいという声があれば、説明や配置を見直します。変更前後の条件も確認し、見た目を変えただけで成果がよくなったと決めつけないようにします。

第9章で詳しく学ぶ →

A/Bテスト

エービーテスト

異なる案を比較し、どちらが目的に合う結果を得られるかを確かめる方法です。比べる要素、評価する指標、判断する条件を事前に決めます。

具体例・使い方を見る

たとえば

見出しの案Aと案Bを、条件が偏らないように訪問者へ出し分けます。少ない件数や一日の結果だけで結論を出さず、期間やデータのばらつきにも注意します。

第9章で詳しく学ぶ →

ヒートマップ

ヒートマップ

クリックされた場所や、ページのどこまでスクロールされたかなどを色で見やすく表す図です。LPのどの部分に課題がありそうか、仮説を立てる手掛かりになります。

具体例・使い方を見る

たとえば

途中で離れる人が多い場所を見つけたら、直前の説明が長いのか、必要な情報が不足しているのかを調べます。色だけで、利用者の気持ちや離脱理由を断定はできません。

第9章で詳しく学ぶ →

第10章業種別・海外・継続施策

ローカライズ

ローカライズ

商品やページを、届ける国・地域の言葉や習慣、利用環境に合わせて調整することです。文章の翻訳だけでなく、提案内容や見せ方も見直します。

具体例・使い方を見る

たとえば

海外向けLPでは、現地で伝わる言葉に加え、通貨、問い合わせ方法、写真や実績の伝わり方も確認します。日本向けのページをそのまま翻訳すればよいとは限りません。

第10章で詳しく学ぶ →

CRM（顧客関係管理）

シーアールエム

お客様の情報や対応履歴を整理し、関係を継続して育てる考え方や仕組みです。それを支援するシステムをCRMと呼ぶこともあります。

具体例・使い方を見る

たとえば

LPから来た問い合わせについて、相談内容、対応担当、商談の状況を記録します。情報を適切に管理し、担当が変わっても必要な対応を引き継げるようにします。

リードナーチャリング

リードナーチャリング

すぐには購入しない見込み客にも、検討に役立つ情報を届け、関係を育てる取り組みです。相手の関心や検討段階に合わせて案内します。

具体例・使い方を見る

たとえば

資料を請求した人へ、希望する配信に応じて事例や選び方を案内します。繰り返し売り込むことが目的ではなく、必要な判断を助ける情報を届けます。
